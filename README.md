# Simulation of Several KF Variants

A C++ simulation framework for **3D angle-only target tracking** and comparison of several nonlinear filtering methods.

The simulation scenario is based on the paper:

> **Angle-only Filtering in 3D using Modified Spherical and Log Spherical Coordinates**

The project provides a common simulation environment for evaluating different state estimation methods under the same target trajectory and angle-only measurement conditions.

## Implemented Methods

* **EKF** — Extended Kalman Filter
* **UKF** — Unscented Kalman Filter
* **PF** — Particle Filter
* **UPF** — Unscented Particle Filter
* **PCRLB** — Posterior Cramér–Rao Lower Bound
* **MSC-EKF** — Modified Spherical Coordinates EKF *(work in progress)*

The filters are evaluated using **RMSE** and Monte Carlo simulations. PF and UPF are included to investigate particle-based approaches, while PCRLB provides a theoretical lower bound for comparison.

## Simulation

The target is simulated in a 3D Cartesian coordinate system with process noise and observed using **angle-only measurements** consisting of bearing and elevation.
The same simulated trajectory and measurement data are used to compare the different filtering methods. Performance is evaluated using RMSE and Monte Carlo simulations.

The **MSC-EKF** implementation is currently under development.

## How to Run

The project uses a Makefile for building and running the simulation.

From the project root:

```bash
make clean
make
make run
```

After the simulation finishes, the RMSE data is generated as JSON files in:

```text
json/
```

The Python scripts in the `python/` directory can then be used to visualize the generated data.

For example:

```bash
cd python
python3 plot_rmse.py
```

The plotting scripts read the JSON files generated by the simulation and produce the corresponding RMSE plots.
